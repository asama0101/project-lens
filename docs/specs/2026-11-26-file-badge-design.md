# 読み込み中のファイルの表示（仕事 D）

## 目的と理由
共有ファイル（`data.json`）と個人ファイル（`personal.json`）のどれを読み込んでいるかが、画面から分からない。案件・フォルダが複数あると、別のファイルを開いたまま気づかず、編集してしまうおそれがある。

## ゴール / 非ゴール / アンチゴール
- ゴール: ヘッダーに、読み込み中の共有・個人ファイルの札を出し、押すと詳細（ファイル名・中身の手がかり・更新日時・書き込めるか）と「別のファイルを選ぶ」が出る。`npm test` が通る。
- 非ゴール: フォルダの場所（パス）を出す（ブラウザが渡さない）。ファイルの自動の切り替え。複数のファイルの履歴。
- アンチゴール: ファイルの読み書き・競合検知の動きが変わる。保存の対象が変わる。

## 制約
- Windows 専用、Node 24 以上。`src/` を変えたら `npm run build` して `assets/project-lens.html` をコミットする。
- 画面に ID を出さない。文言は日本語。`esc()` で必ずエスケープ。用語は「タスク」。
- PR 本文に、「`development.md`: 直した節の名前」を書く。`README.md`・`docs/guide.md` の画面の説明も直す。

## 決めたこと（画面案: https://claude.ai/artifact/XMgsn5V7nAXrRRrGYTicTb の案 2。利用者が選んだ）

### 1. ヘッダーの札
- ヘッダーの右（今の「別の共有ファイル」「別の個人ファイル」のボタンの場所）に、札を 2 つ出す: 「共有 `data.json`」「個人 `personal.json`」。名前は、読み込んだファイルの実際の名前。点の色: 書き込める＝緑、読み込み専用＝橙。
- 「別の共有ファイル」「別の個人ファイル」のボタンは、ヘッダーから外し、札の詳細に移す。ファイルを読み込んでいないときの画面（「共有ファイルを選んでください」）は、今のまま。
- 札を押すと、その札の詳細を、札の下に開く（同時に 1 つ）。もう一度押す・外を押す・Escape・画面の移動で閉じる。開閉の状態は、メモリだけ（`S.fileInfo`）。

### 2. 詳細の中身
- 共有: ファイル名・プロジェクト（先頭 3 件の名前、4 件以上なら「ほか N 件」）・タスク（N 件、うち Done M 件）・更新日時・保存（「書き込めます」か「読み込み専用」）。ボタン「別の共有ファイルを選ぶ」。
- 個人: ファイル名・作業枠と実績の区間の数（`sessions` の件数）・会議の数・更新日時・保存・ボタン「別の個人ファイルを選ぶ」。
- 更新日時は、ファイルの更新日時（読み込んだ時点か、直近の保存の時点。`store` の `loadedAt`）を「YYYY/MM/DD HH:MM」（ローカル時刻）で出す。「更新」ボタンで読み直したら、更新される。
- 書き込めるか: `showOpenFilePicker` で開いたファイル（ハンドルがある）なら「書き込めます」。使えないブラウザ（ファイルを選ぶ入力で開いたとき）は「読み込み専用」。ファイル名は、分かる範囲で出す（分からなければ「選んだファイル」）。更新日時は、分からなければ「—」。

### 3. 作り
- 純関数 `renderFileChips(data, info, open)`（新しい `ui/views/filechips.js`）が、札と詳細の HTML を返す。`info` は `{ shared: { name, at, writable }, personal: { name, at, writable } }`。
- `store.js`: `createStore` に、今のファイルの `{ name, at }` を返す `info()`、`createPairStore` に `{ shared, personal }` を返す `info()` を足す（読み書きの動きは変えない）。
- 結線は `app.js`（`data-fileinfo="shared|personal"`・`data-open`（既存の、ファイルを選ぶ処理）・`S.fileInfo`）。ヘッダーの `filebar` の描画は、その札に置き換える。

## 作る側に任せること
- 札・詳細の細かい見た目（既存の `.chip-btn`・`.btn`・トークンに合わせる。詳細の置き方・幅）。狭い幅での折り返し。

## 見送った案
- ヘッダーの下に、細い行を常に出す（案 1）: 利用者が案 2 を選んだ。画面が約 30px 減る。
- 設定画面だけに出す（案 3）: 「いま、どのファイルか」を見たい目的には遠い。
- フォルダの場所を出す: ブラウザが、ファイル名と更新日時しか渡さない。

## 確かめること
- 単体テスト: 札が 2 つ出る（名前・点の色）。詳細が `open` のときだけ出る。プロジェクト名（3 件まで・「ほか N 件」）・タスク件数・更新日時の書式。読み込み専用の表示。ボタン（`data-open`）が詳細に出て、ヘッダーに無い。`info()` が名前と更新日時を返し、読み書きは変わらない。ID が出ない。
- Playwright（Chromium）で、デモデータ: 札・詳細の開閉・「別のファイルを選ぶ」・幅の狭いとき。確かめていない画面は「未確認」と書く。
